# Aula 02 — Primeiros passos com Haskell e GHCi

Nesta aula vamos começar a usar o **GHCi** e perceber a ideia central da programação funcional em Haskell: um programa é construído através da **avaliação de expressões** e da **composição de funções**.


## 1. Exploração inicial no GHCi

Começa por abrir o terminal e executar:

```bash
ghci
```

Depois experimenta as seguintes expressões:

```haskell
2 + 3
5 * 10
2 ^ 8
True && False
not True
5 == 5
5 /= 3
succ 10
max 10 20
min 4 7
```

Experimenta também consultar tipos com o comando ``:t`` ou ``:type``:

```haskell
:t 2 + 3
:t True
:t 'a'
:t "abc"
:t ['a','b','c']
```

Lembra-te !!!! : `:t` é um comando do GHCi para perguntar o tipo de uma expressão.

## 2. Exercício orientado — primeiras funções

Durante a aula vamos construir, discutir e testar as seguintes funções:

```haskell
dobro x = 2 * x
quadrado x = x * x
media x y = (x + y) / 2
positivo x = x > 0
```

#### `dobro`

```haskell
dobro x = 2 * x
```

A função recebe um valor `x` e devolve o dobro desse valor.

Exemplos:

```haskell
dobro 4
dobro (-3)
dobro 0
```

#### `quadrado`

```haskell
quadrado x = x * x
```

A função recebe um valor `x` e multiplica esse valor por si próprio.

Exemplos:

```haskell
quadrado 5
quadrado (-4)
quadrado 0
```

#### `media`

```haskell
media x y = (x + y) / 2
```

A função recebe dois valores e devolve a média aritmética.

Exemplos:

```haskell
media 10 20
media 5 6
media (-2) 2
```

#### `positivo`

```haskell
positivo x = x > 0
```

A função recebe um valor e devolve `True` se esse valor for maior do que zero; caso contrário, devolve `False`.

Exemplos:

```haskell
positivo 3
positivo 0
positivo (-5)
```

## 3. Guardar as funções num ficheiro

Cria um ficheiro chamado `funcoes.hs` e coloca lá as definições das funções:

```haskell
dobro x = 2 * x
quadrado x = x * x
media x y = (x + y) / 2
positivo x = x > 0
```

No GHCi, carrega o ficheiro com:

```haskell
:l funcoes.hs
```

Depois testa:

```haskell
dobro 10
quadrado 7
media 10 14
positivo (-3)
:t dobro
:t media
:t positivo
```

## 5. Desafio

Implementa a função:

```haskell
converteCelsius :: Double -> Double
```

A função deve converter uma temperatura em **Fahrenheit** para **Celsius**.

Fórmula:

```text
C = (F - 32) * 5 / 9
```

Exemplos para testar:

```haskell
converteCelsius 32     -- 0.0
converteCelsius 212    -- 100.0
converteCelsius 98.6
```
