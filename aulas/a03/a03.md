# Aula 03 — Listas, tuplos, pattern matching e guardas

Nesta aula vamos resolver os exercícios da **Ficha PL1 — Partes 2 e 3**. O objetivo é aprender a trabalhar com listas e tuplos, decompor estruturas e definir funções por casos em Haskell.

## 1. Listas

Uma lista contém elementos do mesmo tipo. Experimenta no GHCi:

```haskell
[1, 2, 3]
1 : [2, 3]
[1, 2] ++ [3, 4]
head [10, 20, 30]
tail [10, 20, 30]
length [10, 20, 30]
```

Observa a diferença entre o operador `(:)`, que acrescenta um elemento no início de uma lista, e o operador `(++)`, que concatena duas listas.

## 2. Tuplos

Ao contrário das listas, um tuplo pode guardar valores de tipos diferentes e tem um número fixo de componentes.

```haskell
("Ana", 18)
fst ("Ana", 18)
snd ("Ana", 18)
```

Exemplos de funções sobre pares:

```haskell
somaPar (x, y) = x + y
troca (x, y) = (y, x)
```

## 3. Pattern matching

O **pattern matching** permite decompor valores diretamente nos argumentos de uma função.

```haskell
primeiro (x, _) = x
segundo (_, y) = y

primeiroElemento (x:_) = x
```

Também permite definir uma função através de vários casos:

```haskell
eZero 0 = True
eZero _ = False
```

Ao trabalhar com listas, é importante considerar separadamente a lista vazia e uma lista com cabeça e cauda:

```haskell
comprimento [] = 0
comprimento (_:xs) = 1 + comprimento xs
```

## 4. Guardas

As guardas permitem escolher o resultado de uma função através de condições.

```haskell
sinal x
  | x > 0     = 1
  | x == 0    = 0
  | otherwise = -1
```

A ordem das guardas é importante: as condições são verificadas de cima para baixo.

## 5. Funções definidas por casos

Durante a resolução da ficha, identifica qual destas técnicas é mais adequada em cada exercício:

- pattern matching para decompor tuplos e listas;
- várias equações para distinguir casos concretos;
- guardas para escolher um resultado com base em condições;
- expressões `if ... then ... else ...` para decisões simples.

Exemplo:

```haskell
classificaNota nota
  | nota < 0 || nota > 20 = "nota inválida"
  | nota >= 10            = "aprovado"
  | otherwise             = "reprovado"
```
