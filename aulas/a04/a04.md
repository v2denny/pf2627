# Aula 04 — Recursão I

Nesta aula vamos resolver os exercícios da **Ficha PL1 — Parte 4**. O objetivo é compreender a recursividade e construir funções recursivas sobre números e listas.

## 1. Ideia de recursividade

Uma função recursiva é uma função que se chama a si própria para resolver uma versão mais pequena do mesmo problema.

Uma definição recursiva deve ter:

- um **caso base**, que produz um resultado sem nova chamada recursiva;
- um **caso recursivo**, que reduz o problema e chama novamente a função.

## 2. Recursão sobre números

Exemplo: calcular a soma dos números de `1` até `n`.

```haskell
somaAte :: Int -> Int
somaAte 0 = 0
somaAte n = n + somaAte (n - 1)
```

Avaliação de `somaAte 3`:

```text
somaAte 3
= 3 + somaAte 2
= 3 + 2 + somaAte 1
= 3 + 2 + 1 + somaAte 0
= 3 + 2 + 1 + 0
= 6
```

Outro exemplo:

```haskell
fatorial :: Int -> Int
fatorial 0 = 1
fatorial n = n * fatorial (n - 1)
```

## 3. Recursão sobre listas

Uma lista pode ser vista como:

- a lista vazia, `[]`;
- um primeiro elemento `x` seguido de uma lista `xs`, representada por `(x:xs)`.

Esta estrutura conduz naturalmente a definições recursivas:

```haskell
comprimento :: [a] -> Int
comprimento [] = 0
comprimento (_:xs) = 1 + comprimento xs
```

```haskell
somaLista :: Num a => [a] -> a
somaLista [] = 0
somaLista (x:xs) = x + somaLista xs
```

```haskell
produtoLista :: Num a => [a] -> a
produtoLista [] = 1
produtoLista (x:xs) = x * produtoLista xs
```

## 4. Construir uma função recursiva

Antes de escrever o código, responde às seguintes perguntas:

1. Qual é o caso mais simples do problema?
2. Que resultado deve produzir esse caso base?
3. Como posso reduzir o argumento?
4. Como combino o resultado da chamada recursiva com o valor atual?

Em funções sobre listas, começa normalmente por distinguir estes padrões:

```haskell
funcao [] = ...
funcao (x:xs) = ... funcao xs ...
```

## 5. Cuidados importantes

- Garante que existe um caso base.
- Confirma que cada chamada recursiva aproxima o argumento do caso base.
- Testa a função com `0` ou com `[]`, conforme o tipo do problema.
- Testa também valores pequenos para acompanhares a avaliação passo a passo.
- Considera explicitamente como a função deve tratar argumentos inválidos, quando aplicável.

## 6. Trabalho da aula

Resolve os exercícios da **Ficha PL1 — Parte 4**. Para cada função:

1. escreve a assinatura de tipo;
2. identifica o caso base;
3. define o caso recursivo;
4. acompanha manualmente pelo menos uma avaliação;
5. testa a implementação no GHCi.

Podes guardar as soluções num ficheiro Haskell e carregá-lo com:

```bash
ghci nome-do-ficheiro.hs
```

ou, dentro do GHCi:

```haskell
:l nome-do-ficheiro.hs
:r
```
