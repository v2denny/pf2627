# Aula 01 — Introdução a Haskell

Nesta aula é apresentado um pequeno exemplo de processamento de dados de alunos em **Haskell**.

## Ficheiros

* `Main.hs` — programa principal.
* `alunos.txt` — ficheiro com os nomes e notas dos alunos.

O ficheiro `alunos.txt` segue o formato:

```text
Nome;Nota
```

Exemplo:

```text
Ana;15
Bruno;8
Carlos;12
```

## Programa

O programa lê os alunos a partir de `alunos.txt` e apresenta:

* os alunos aprovados;
* a melhor nota;
* a pior nota;
* a média da turma.

## Executar

Na pasta da aula, utilizando o GHCi:

```bash
ghci Main.hs
```

e depois:

```haskell
main
```

> ATENÇÃO: O ficheiro `alunos.txt` deve estar na mesma pasta que `Main.hs`.
