# Programação Funcional

Repositório de apoio à unidade curricular de **Programação Funcional**.

Aqui serão disponibilizados os exemplos utilizados nas aulas, exercícios, fichas práticas, projetos e outros materiais de apoio à unidade curricular.

## Estrutura do repositório

```text
.
├── aulas/       # Exemplos e código desenvolvido nas aulas
├── projetos/    # Projetos e exercícios de maior dimensão
└── recursos/    # Material de apoio
```

## Aulas

Os materiais utilizados em cada aula encontram-se organizados por diretório:

```text
aulas/
├── a01/
├── a02/
├── a03/
└── ...
```

Cada diretório poderá conter exemplos de código, dados utilizados durante a aula e exercícios associados aos conteúdos abordados.



## Ambiente de desenvolvimento

Ao longo da unidade curricular será utilizada a linguagem **Haskell**.

É recomendada a instalação de:

* GHC
* GHCi
* Cabal
* Git
* Visual Studio Code (recomendado) ou outro editor com suporte para Haskell

**- As instruções adicionais de configuração estão disponíveis na pasta `recursos/`.**


## Utilização do repositório

Recomenda-se que os alunos mantenham os seus exercícios e alterações pessoais fora deste repositório ou numa cópia/fork próprio, de forma a evitar conflitos durante as atualizações.
